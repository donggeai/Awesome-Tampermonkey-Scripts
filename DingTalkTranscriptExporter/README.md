# 钉钉AI听记导出神器 (DingTalk AI Transcript Exporter)

🚀 一键导出钉钉AI听记的转写内容、AI纪要和章节信息，支持Markdown、HTML、TXT格式导出和复制。

## ✨ 功能特性

- 📝 **转写内容导出**: 自动滚动加载并提取完整的转写对话内容（支持虚拟滚动）
- 🤖 **AI纪要导出**: 完整导出AI生成的纪要，保留标题、列表、加粗等Markdown格式
- 🖼️ **图片链接保留**: AI纪要中的可视化摘要图片链接完整保留
- 📑 **章节信息导出**: 导出AI自动生成的章节摘要和时间戳
- 🎯 **多格式支持**: 支持 Markdown、HTML、TXT 三种格式导出
- 📋 **一键复制**: 快速复制内容到剪贴板
- 🔄 **灵活选择**: 可自由选择导出转写、AI纪要、章节的任意组合
- 🎨 **美观界面**: 钉钉风格的现代化用户界面

## 🛠️ 安装方法

### 前置要求
- 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展
- 支持的浏览器：Chrome、Firefox、Safari、Edge

### 安装步骤
1. 点击安装脚本链接（即将上线）
2. Tampermonkey 会自动打开安装页面
3. 点击「安装」按钮完成安装

### 手动安装
1. 复制 `DingTalkTranscriptExporter.user.js` 文件内容
2. 打开 Tampermonkey 管理面板
3. 点击「添加新脚本」
4. 粘贴代码并保存

## 📖 使用指南

### 支持的页面
- 钉钉AI听记页面：`https://shanji.dingtalk.com/app/transcribes/*`

### 基本使用
1. 打开钉钉AI听记页面
2. 等待页面完全加载（转写内容和AI纪要已显示）
3. 点击页面右上角的「📤 导出听记」按钮
4. 在弹出的对话框中：
   - **选择导出内容**: 勾选 AI纪要、章节、转写（可多选）
   - **选择导出格式**: Markdown / HTML / TXT
   - **选择导出方式**: 下载文件 或 复制到剪贴板

### 导出内容说明

#### AI纪要
- 包含会议/通话的AI生成纪要
- 保留完整的Markdown格式（标题、列表、加粗、引用等）
- 包含可视化摘要图片链接
- 包含AI洞察内容

#### 章节
- AI自动识别的章节划分
- 每个章节包含时间戳、标题和内容摘要

#### 转写
- 完整的语音转文字内容
- 包含发言人姓名和时间戳
- 支持虚拟滚动自动加载全部内容

## 📄 导出格式说明

### Markdown 格式
```markdown
# 听记标题 - AI纪要

**导出时间**: 2026-04-04 10:00:00

---

![AI听记可视化摘要](图片链接)

> **主题**: AI算法岗技术面评估
> **时间**: 2026-04-03 21:56:51
> **参与人**: 唐东, zy, 张倩

## 面试概况

本场面试为AI算法岗位的技术面，时长**约35分钟**...

## 候选人画像

- **教育背景**：本科与研究生均就读于**中央财经大学电子信息专业**
- **工作经历**：
  - 第一份工作：中国网安...
  - 当前公司：...
```

### HTML 格式
- 包含完整的HTML文档结构
- 钉钉风格CSS样式，美观易读
- 适合在浏览器中查看或打印

### TXT 格式
- 纯文本格式，兼容性最佳
- 结构化排版，便于阅读

## 🐛 故障排除

### 常见问题

**Q: 点击导出按钮没有反应？**
A: 请确保页面已完全加载，转写内容或纪要已显示。可以尝试刷新页面后重试。

**Q: 导出的转写内容不完整？**
A: 脚本会自动滚动加载全部转写内容。如果内容较长，请耐心等待加载完成。

**Q: 复制功能不工作？**
A: 请检查浏览器是否允许访问剪贴板。在某些浏览器中需要用户手动授权。

**Q: AI纪要格式不正确？**
A: 脚本会尽力保留原始格式。如果格式有问题，可以尝试导出HTML格式。

### 调试方法
1. 打开浏览器开发者工具（F12）
2. 查看控制台是否有错误信息
3. 确认Tampermonkey脚本已启用
4. 检查页面元素是否正确加载
